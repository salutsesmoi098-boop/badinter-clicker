# Badinter Clicker

Jeu en ligne : https://salutsesmoi098-boop.github.io/badinter-clicker/

Version publique minifiée. Le code source lisible n'est pas publié dans ce dépôt.

Le classement mondial et le salon public sont partagés en ligne via MantleDB, sans compte ni paiement. Les comptes, les sauvegardes, les messages privés et le panneau admin restent locaux à chaque appareil.

Le jeu envoie au maximum un petit signal de maintien par jour et par navigateur pour éviter la purge des espaces inactifs. Sans aucune visite pendant 30 jours, le service peut effacer le classement et le chat public.
